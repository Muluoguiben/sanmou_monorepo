# Sanmou Shared Memory

This is the workspace shared memory vault for `sanmou_monorepo`.

Read order for future agents:

1. `shared-memory/AGENTS.md`
2. `shared-memory/TODO.md`
3. `shared-memory/projects/sanmou.md`
4. task-specific files under `agent/`, `people/`, or `notes/`

Canonical project truth still lives in:

- `AGENTS.md`
- `todo-list.md`
- `docs/`
- checked-in tests and fixtures

Shared memory is for rolling context: decisions, blockers, owners, links, and next steps that should not be lost between chats.

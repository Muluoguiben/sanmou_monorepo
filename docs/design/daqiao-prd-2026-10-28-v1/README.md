# 大乔 PRD v1 评审包

2026-10-28。新增版本，保留旧原型和评审稿；不修改业务代码。

- [PRD 阅读版](PRD.html)：设计样图已内嵌，可点击放大。
- [PRD Markdown 原稿](PRD.md)：正式内容载体，方便评审和后续修改。
- [设计样图源](mockups.html#chat)：通过页面导航／hash 查看不同场景。
- [校验结果](verification.json)：图片、引用和阅读布局的检查；不代表产品功能或模型调用已验收。

样图共十个场景：大乔会话、账号会话、任务列表、任务详情、模型设置、添加模型服务、早晚简报、Dev 调试、绑定账号、账号规则。均使用示例数据，不连接模型和游戏。

本版以 2026-10-27 至 2026-10-28 对话确认的产品决定为准。设置中尚未讨论完的具体项列为待评审；旧 v2 中的总览、地图、可见知识库、语音及人工接管入口不再沿用。

`build-prd.mjs` 用本机已有的报告渲染器和浏览器生成 PNG、HTML 与校验结果，只用于重建设计文档，不是应用业务代码。

## Language

**登录账号**：登录游戏服务使用的用户身份，可以关联多个区服角色。
_Avoid_：用账号同时表示角色进度或游戏窗口。

**区服角色**：登录账号在指定区服拥有的独立游戏身份和进度主体。
_Avoid_：将同账号的不同角色称为独立登录账号。

**客户端实例**：承载一个角色游戏会话的客户端进程及窗口。
_Avoid_：将客户端实例等同于角色或模型副本。

**Agent 会话**：围绕一个客户端实例与区服角色持续维护的任务、观察和决策上下文。
_Avoid_：多个窗口共享同一段角色历史。

**角色成长轨迹**：一个区服角色从初始化到成长的有序记录，可包含多个短任务。

**任务 episode**：在给定起点和限制下，由明确结束判据界定的一次任务尝试。
_Avoid_：将换角色描述为恢复完全相同的中间游戏状态。

**任务规格**：某类游戏任务的目标、开始条件、行动范围、预算和结束判据的约定。

**决策轨迹**：按时间关联任务、观察、行动与环境反馈的序列，每一步只使用当时可获得的信息。
_Avoid_：把孤立问答或模型编造的执行反馈当作真实轨迹。

**感知观察**：从特定时刻画面获得的可见事实和明确未知项，不是游戏全部真实状态。
_Avoid_：用攻略补造当前角色状态。

**决策上下文快照**：某次角色决策实际获得的目标、观察、知识证据、历史与工具定义的完整快照。

**任务权限范围**：一项任务获准作用的区服角色、窗口、动作、目标与资源额度。

**输入事务**：针对同一角色和窗口的一组目标复核、输入及必要验证，执行期间独占相关输入资源。

**角色绑定**：区服角色会话与客户端、观察来源及窗口身份的经验证关联；绑定修订后旧请求失效。

**固定动作意图**：一次语义动作开始后保持不变的目标和预期结果；中间步骤用新观察重新核对，不重新选择另一个目标。

**动作 operation**：一次业务行动意图及其连续步骤的身份；不同于动作类型、稳定语义 action ID 或单次输入 attempt。

**结果不明**：输入可能已经产生，但尚无足够证据确认其效果的状态；需要重新观察和对账。

**输入租约**：某个 Agent 在有限时间内占用主机输入资源的凭证，不等于执行某项游戏动作的授权。

**动作账本**：游戏行动从意图、派发到结果确认的持久记录，用于处理不可逆操作的恢复与对账。

**决策 Trace**：通过因果关联串起一次角色决策的观察、上下文、模型、工具、权限、执行和验证过程的记录。

**语义动作**：带明确游戏目标和参数的行动意图，例如领取某章奖励或升级指定建筑。
_Avoid_：将一次物理点击自动视为一次策略决策。

**初始化流程**：把获准使用的角色准备到任务开始条件的流程，可包含选服、创角、教程和预算内抽卡。

**动作来源**：行动由人工、固定流程、教师模型或训练策略产生的归属。
_Avoid_：将脚本接管操作归为模型自主决策。

**任务成功证据**：与角色、目标及本次行动关联，能支持完成判定的实际观察和结果。
_Avoid_：把点击成功、模型宣称完成或计时开始直接当最终成功。

**评测规格**：在运行前固定的输入、能力要求、判据、指标分母与阈值。

**运行证据包**：一次评测的版本、实际调用能力、逐项结论及原始证据引用，不另造一套运行事实。

**基模与策略模型**：基模是继续训练的起点，策略模型是训练前后在系统中承担行动选择的模型角色。
_Avoid_：认为必须部署两个独立的大脑。

# 云网关重启与异常处理验收

日期：2026-10-29。此前已完成 Mac 经 SSH 隧道连接 Colab 真实模型的两轮测试，详见[实测记录](mac-colab-gateway.md)。本批准备可重复启动与异常验收工具，并在独立 A100 上进行了真实模型测试。本地模拟与真实云端结果分别记录。

本批专用 A100 由 CLI 创建；重复启动脚本在 GPU 上返回就绪，SGLang 0.5.22 的 `/v1/loads` 返回 HTTP 200，测试基线的运行中和排队请求均为 0。真实并发、超时及断连测试结果见下文。

## 本批准备

- [重复启动脚本](../../../scripts/model-serving/restart_colab_gateway.py)：针对已经准备好的 Colab 环境，核对来源和硬件条件，为每次运行生成独立目录、密钥、端口及新的模型绑定，然后启动模型服务和网关。它不负责创建或删除 Colab 运行时。本批 GPU 启动已返回就绪，异常清理的实际云端行为仍需验收。
- [异常验收脚本](../../../scripts/model-serving/gateway_resilience_probe.py)：复用项目网关和模型后端，通过单独的测试网关观察并发、超时与断连。每个模式分别记录请求身份、网关计数和后端事件；输出只存脱敏的测试记录。
- 主管在 Mac 本地运行组合回归共 **24 项全部通过**：重复启动脚本 14 项，异常验收脚本 10 项，含提示内容与采样配置绑定的负例。测试使用模拟后端和回环 HTTP。独立复核提出了监听端口归属、进程组清理、排队请求和取消事件顺序等问题，已纳入修复与复核。
- 使用 Colab CLI 自动创建独立 Linux CPU 会话，实测进程组监听端口识别：本组监听识别成功，外组和 `0.0.0.0` 监听被拒绝，外组未收到请求；网关健康检查符合预期，测试创建的三个子进程退出。测试前后的 CLI 列表完整行集合相同，未操作其他会话。原始记录的 `baseline_count`／`post_count` 按 `[` 开头的输出行计数，可能包含“没有活动会话”的提示，不能作为实际会话数量。[测试源码和结果索引](gateway-resilience-preparation/evidence-index.json)已归档；该测试不包含 GPU 或真实模型。

## 真实 GPU 验收结果

测试使用真实 SGLang 0.5.22 和模型，三个异常探针均在云机回环链路中执行；它们不是 Mac 与云之间的断网测试。以下耗时和负载来自工具摘要，没有完整的 HTTP 和 `/v1/loads` 时间序列。

- 合成长请求对照返回 200，耗时 100.429 秒，token 记录为 512／2048；结束原因是 `length`，不作为完整工具调用结果。
- 网关并发上限设为 1：首个请求返回 200，第二个返回 503，只观察到一次上游 HTTP 正文发送；本次约 87.742 秒，负载回零。
- 网关 15 秒超时返回 504，观察到后端协程被取消并退出，负载回零。
- 客户端断连后网关记录 `cancelled=1`；观察到同一后端协程取消并退出，负载回零。
- 异常测试后，Mac 经 SSH 调用恢复两轮成功，耗时 2.094／2.695 秒，共 1088 token，预算待结算为 0。

本轮没有 native request ID 或指定请求解码停止的证据；负载回零和 HTTP／后端协程取消不能证明引擎已中止该请求，**引擎级取消仍未通过**。本任务模型和网关已停止，受管进程组数量为 0，GPU 计算进程列表为空。用户明确允许释放本次 CLI 专用 A100 后，主管核对会话与目标运行时并执行停止；后端复查目标 assignment 和其他 assignment 均为 0，本地对应会话已移除。运行时资源已释放，本轮机器的临时状态已清除。[GPU 证据索引](gateway-resilience-gpu/evidence-index.json)由主管归档。

## 真实 GPU 操作入口

使用已经开启并完成环境准备的 A100，先核对 GPU、空闲状态、现有进程、来源清单和模型文件；每次指定新的独立输出目录。先查看两项入口的参数：

```bash
python scripts/model-serving/restart_colab_gateway.py --help
python scripts/model-serving/gateway_resilience_probe.py --help
```

第二项在包含项目 Python 包及其依赖的环境中运行。启动脚本要求提供本轮环境准备状态文件、完整源码提交和来源清单哈希，并生成新的绑定及私有密钥。验收探针只接受云端回环地址、与本轮模型清单匹配的 `PolicyRequest` 请求文件，以及独占空闲服务的明确声明；密钥通过环境变量提供，不放入命令、输出或日志。每种模式使用独立的新输出文件。

先完成一次正常请求，再分别执行 `concurrency`、`timeout` 和 `disconnect`。探针只有在请求已发送且隔离服务观测到运行中负载后才触发异常步骤；请求过快结束、监控字段缺失或负载未归零时不得记为通过。短请求可能自然结束，超时场景需要足够长的请求。引擎停止生成仍需额外的请求级证据。

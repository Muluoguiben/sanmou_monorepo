## Implemented boundary

`scalar_profile` means only an exact single-hero canonical/alias question about
base/max/growth military/intelligence/command/initiative. It does not mean full
profile or semantic validation. Lineup hero members are not entity anchors.
Ambiguous aliases, unsupported wording, skills, conditions and free-text remain
`partial + unassessed`, preserving the existing evidence-backed generation path.
Wrong-entity final retrieval is not supported; history rewrite cannot change
the subject used by the assessor. Retrieval score/confidence do not determine
support or select a true source.

Only unconditional static profile slots are compared. Nonempty free-form
constraints are unassessed, not interpreted as equivalent applicability.
Zero is a value; None is missing. Missing scalar slots do not prove absent
prose and do not force refusal. All profile notes remain available in the
prompt. Assessed nonempty fields are added with exact path/value/entry/source
inside actual evidence sent to the model. Conflicts show every relevant
nonempty field source deterministically and make zero answer calls. Empty
retrieval retains zero rewrite/answer calls. Existing citation-ID checks remain.
